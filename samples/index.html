Minimotor Samples

Small games built with the Minimotor engine

Open with pnpm samples — running locally via file:// won't load ES modules.

Minimal

EngineInput

Absolute minimum: a colored square that moves with arrow keys. Demonstrates initCanvas, onKeyDown, and the game loop.

Bounce

EngineStorageInput

Ball bounces off walls. Each wall hit earns a point. Best score saved with Storage.

Pong

CollisionStoragePhysics

Paddle + ball. Uses Collision.rectsOverlap for paddle hits. Ball speed ramps up. Best score persisted.

Particles

SpritesPhysics

200-spark firework effect. Click to spawn. Gravity from Physics pulls sparks down. Spark texture pre-rendered with Sprites.getSprite.
